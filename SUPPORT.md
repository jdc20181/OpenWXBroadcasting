# Getting help

| You want to… | Go to |
|---|---|
| Set up a new station | The first-run wizard in the app, or `openwx setup` in a terminal |
| Check that the weather feeds work | Settings > General > Backend > *Check feeds*, or `openwx status` |
| Report a bug | In the app: *Help > Report a bug*; or a GitHub issue (*Bug report* template) |
| Ask for a feature or graphic | A GitHub issue (*Feature request* template) |
| Report a security problem | Privately: see [SECURITY.md](SECURITY.md) |
| Run a shared relay server | [server/README.md](server/README.md) |
| Connect Claude or another AI assistant | [prompts/README.md](prompts/README.md) |

When asking for help, include your version (Settings > About) and what you expected to happen.
OpenWX is a community project maintained by volunteers: answers may take a few days.

**OpenWX is not an official warning source.** For life-safety decisions follow the National
Weather Service and your local emergency management.
