# OpenWX Broadcasting v0.1.0 (alpha)

The first public pre-release of OpenWX Broadcasting: a weather studio for community stations,
volunteers and weather enthusiasts. Live radar maps, on-air graphics, shows and severe weather
coverage, built on free public data from NOAA and the National Weather Service.

This is an alpha. Expect rough edges, and please report what you find.

> OpenWX is not an official warning source. For life-safety decisions, follow the National
> Weather Service and your local emergency management.

## What's in it

**The studio**

- **Map Studio:** radar and satellite loops, NWS warnings and watches, SPC severe outlooks,
  drought, earthquakes, rivers, lightning, and NOAA model data (HRRR and GFS).
- **Graphics Studio:** about 2,000 ready-made graphics: forecasts, severe weather, winter,
  tropics, climate, safety and holiday cards. Edit any of them or make your own.
- **Show Builder and Severe Weather Mode:** build a rundown, take graphics to air, and switch
  to wall-to-wall coverage when warnings come in.
- **Output:** a second screen, OBS, and video and image export.

**Setup that doesn't need a manual**

- A setup wizard on first launch: your station name, a contact for the National Weather
  Service, your state, the counties you cover and your main city. Everything is set from
  those answers. Run it again any time from Settings > Weather.

**Built-in weather backend**

- OpenWX Relay runs inside the app on your PC and fetches the weather data. Nothing to host,
  no account, no API keys.
- Running several studio PCs? Put the relay on your own Linux server and point each PC at it
  (`server/install.sh` installs, updates and removes it).

**AI assistants**

- The `openwx` command-line tool includes an MCP server, so Claude and other assistants can
  read your station's forecast, alerts and severe outlook, set up your region, and help write
  forecast posts and severe weather briefings. Ready-made prompts are in `prompts/`.

## Getting started

1. Download `openwx-broadcaster_0.1.0-build3_x64-setup.exe` below and run it. No admin rights
   needed.
2. Windows may say it "protected your PC", because this alpha isn't code-signed yet. Choose
   **More info**, then **Run anyway**.
3. Answer the setup wizard's questions. The map opens on your area.

Prefer a terminal? `openwx setup` asks the same questions.

## System requirements

| | Required | Suggested |
|---|---|---|
| Operating system | Windows 10 or 11, 64-bit | Windows 11 (what OpenWX is developed and tested on) |
| Graphics | DirectX 11, plus DirectX 12 or Vulkan for the map | A dedicated graphics card for on-air output at 1080p |
| Memory | | 8 GB, or 16 GB when running on air with a second screen |
| Disk space | About 1.1 GB (600 MB download) | |
| Screen | | 1920 × 1080, plus a second display for on-air output |
| Internet | Always on: weather data is live and never cached | Broadband |

Optional: OBS Studio for streaming, and an MCP-capable assistant (such as Claude) for the
`openwx` tools.

**Self-hosted relay (optional):** any 64-bit Linux server with systemd (x86-64 or ARM64), or
Docker. This release has no Linux download, so `install.sh --from-source` builds it on the
server (Rust is needed).

## Known limitations

- **No automatic updates yet.** Install new versions over the old one; your settings are kept.
- **The installer isn't code-signed**, so Windows SmartScreen warns on first run.
- **Some forecast extras and air quality still come from Open-Meteo.** Its free tier is for
  non-commercial use. Replacing these with NOAA sources is in progress.
- **Sample graphics and some tests still name Indiana places.** Your own graphics use your
  station's places.
- **Not built yet:** posting forecasts and alerts to Facebook from the app, filing bug reports
  straight to GitHub, and the four app themes.
